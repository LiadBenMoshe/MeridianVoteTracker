# Meridian web (Angular 20)

```bash
npm install
npm start          # http://localhost:4200, proxies /api to http://localhost:8080
npm run build      # production build (used by the Docker image)
npm run gen:api    # regenerate the typed client from openapi/Meridian.Api.json
```

`src/app/api` is generated by ng-openapi-gen. Do not edit it by hand.
